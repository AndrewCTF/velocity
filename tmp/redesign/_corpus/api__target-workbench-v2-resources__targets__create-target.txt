Create Target POST /api/v2/targetWorkbench/targets Create a Target.
Returns the RID of the created Target. 
 If sidc field is specified and invalid according to MIL-STD-2525C specification,
an InvalidSidc error is thrown. 
 Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:target-write .
