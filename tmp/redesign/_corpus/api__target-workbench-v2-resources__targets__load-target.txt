Load Target GET /api/v2/targetWorkbench/targets/{targetRid}/load Load Target by RID. 
 Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:target-read . Path parameters targetRid string The unique identifier for a Target Response body LoadTargetResponse object Success response with the requested Target. The objectRid is the RID of the object being targeted.
