Add Annotations To Map POST /api/gotham/v1/maps/{mapRid}/layers/annotations Warning This endpoint is in preview and may be modified or removed at any time.
To use this endpoint, add preview=true to the request query parameters. 
 Add annotations to a map. Currently only Line, Polygon, Rectangle, Point, and tactical graphic annotations
may be added. If any provided parameters are unknown, invalid, or do not satisfy the security requirements,
the entire request will fail.
For each request, a new element is created for each annotation, as well as a new layer if no parent layer
is specified; thus not idempotent.
Returns the ID of the layer created. Path parameters mapRid string The RID of the Gaia map that you wish to add annotations to. Query parameters preview boolean optional Represents a boolean value that restricts an endpoint to preview mode when set to true.
