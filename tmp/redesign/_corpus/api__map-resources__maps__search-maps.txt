Search Maps GET /api/gotham/v1/maps Warning This endpoint is in preview and may be modified or removed at any time.
To use this endpoint, add preview=true to the request query parameters. 
 Retrieves all published maps containing the mapName (does not have to be exact). Query parameters preview boolean optional Represents a boolean value that restricts an endpoint to preview mode when set to true. mapName string The name of the map(s) to be queried. pageSize integer optional The maximum number of matching Gaia maps to return. Defaults to 50. pageToken string optional The page token indicates where to start paging. This should be omitted from the first page's request. Response body SearchMapsResponse object Success response. Hide child attributes Hide child attributes Expand all results list<GaiaMapMetadata> optional Show child attributes Show child attributes nextPageToken string optional The page token indicates where to start paging. This should be omitted from the first page's request.
