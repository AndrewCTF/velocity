Introduction The Gotham API is a developer-friendly Representational State Transfer (REST) API consisting of HTTP endpoints you can use to interact with and build applications on top of Palantir's Gotham platform. The endpoints use the OAuth 2.0 protocol for authentication and are designed in a common pattern, largely using JSON requests and responses. The API currently supports capabilities for Gotham's RevDB - an object database backed by a dynamic ontology.
