Search Maps GET /api/v2/gaia/maps/search Warning This endpoint is in preview and may be modified or removed at any time.
To use this endpoint, add preview=true to the request query parameters. 
 Retrieves all published maps containing the mapName (does not have to be exact). 
 Third-party applications using this endpoint via OAuth2 must request the following operation scope: api:map-read . Query parameters mapName string The name of the map(s) to be queried. pageSize integer optional The maximum number of matching Gaia maps to return. Defaults to 50. pageToken string optional The page token indicates where to start paging. This should be omitted from the first page's request. preview boolean optional Enables the use of preview functionality.
