Write observations POST /api/gotham/v1/observations Warning This endpoint is in preview and may be modified or removed at any time.
To use this endpoint, add preview=true to the request query parameters. 
 Writes Observations directly to Geotime. Returns the Observations that could not be written to Geotime with the
reason for why they could not be written. Any Observations not in the response are guaranteed to have been
written successfully to Geotime's backing data store. Query parameters preview boolean optional Represents a boolean value that restricts an endpoint to preview mode when set to true. Request body WriteObservationsRequest list<Observation> The list of Observations to write to Geotime.
