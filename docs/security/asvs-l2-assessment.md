# OWASP ASVS 5.0.0 Level 2 assessment

Assessed 2026-09-13 on branch `compliance-2026-09` against every Level 1 and Level 2 requirement of OWASP ASVS 5.0.0 (253 requirements; the standard is in `references/`, not in git). This is a self-assessment, not a third-party certification.

| Verdict | Count | Meaning |
|---|---|---|
| PASS | 159 | Met; evidence is a file:line or a test that fails if the control regresses |
| NA | 42 | The feature the requirement governs does not exist here (proof of absence in the row) |
| DELEGATED | 21 | Met by Supabase Auth (GoTrue) or another named component the app relies on correctly |
| OPERATOR | 17 | Needs a deployment setting the repository cannot hold; every one is on [`operator-hardening.md`](operator-hardening.md) |
| ACCEPTED | 14 | A documented deviation with a risk-register entry, owner and review date ([`isms/risk-assessment.md`](isms/risk-assessment.md)) |
| FAIL / PARTIAL | 0 | — |

Total: 253.

**Method.** Four read-only audits (V1–V5, V6–V7, V8–V10, V11–V17) opened the code for each requirement. The 69 PARTIAL/FAIL results were then fixed test-first by four owners with disjoint files, or resolved as a documented decision; each fix is in the evidence column. Line numbers drift: search by the named function or test.

**Re-assessment.** On every minor release and at the annual management review (`isms/operations.md`). A new route, credential carrier, sidecar or upstream re-opens its chapter.
